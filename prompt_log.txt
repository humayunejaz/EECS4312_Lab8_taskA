- If fewer than N slots are available, the system will return all valid slots found.

Prompt 2

Purpose:
Derive a clear algorithm for generating the next N available meeting slots.

Prompt:
Given:
- working hours [work_start, work_end)
- meeting duration dur
- buffer time buf
- busy intervals list of (start, end) that may be unsorted and overlapping
- desired number of suggestions N

We represent time as integer minutes from start of day.

Design an algorithm that:
1) normalizes busy intervals (sort + merge overlaps/adjacent)
2) applies buffer after each busy interval
3) finds the earliest N available slots of length dur within [work_start, work_end)
4) returns slots in chronological order as (start, end)

Also specify how to handle edge cases:
- no availability
- dur longer than any gap
- buf causes gaps to disappear
- fewer than N slots found

Return the algorithm as step-by-step pseudocode plus a short explanation.

Response Summary:

Algorithm (high-level):
1) Validate inputs:
   - dur > 0, work_start < work_end, N >= 0, buf >= 0.
2) Normalize busy intervals:
   - Filter out intervals completely outside [work_start, work_end).
   - Clamp each interval to [work_start, work_end).
   - Sort by start time.
   - Merge intervals that overlap or touch (if next.start <= curr.end).
3) Apply buffer after each busy interval:
   - For each merged interval (s,e), treat it as (s, min(e+buf, work_end)).
   - After expansion, merge again because buffers can cause new overlaps.
4) Find free gaps:
   - Start pointer = work_start.
   - For each blocked interval (s,e):
       gap = [pointer, s)
       if gap length >= dur:
           take the earliest slot (pointer, pointer+dur) as a suggestion.
           Then advance pointer by dur (or stop at first slot per gap if only returning one per gap).
       pointer = max(pointer, e)
   - After processing all blocked intervals, check final gap [pointer, work_end).
5) Collect slots until N found; if fewer exist, return all found.

Tie-breaking:
- Always choose the earliest possible valid start time (chronological order).

Edge cases:
- If no gaps of length dur exist -> return [].
- If fewer than N slots exist -> return the smaller list.
- If buf eliminates gaps -> return [] accordingly.

Decision:

We will implement the “blocked time” approach:
- Normalize busy intervals (sort/merge),
- Expand ends by buffer,
- Merge again,
- Then scan from work_start to work_end to emit earliest valid slots.
We will return at most one slot per gap (the earliest), continuing scanning after the blocked interval to find further slots until N is reached.
